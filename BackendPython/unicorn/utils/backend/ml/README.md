# Machine Learning Models

This directory contains machine learning algorithms and models for investment analysis.

## Components

- `genetic_algorithm.py` - Genetic algorithm for portfolio optimization
- `neural_networks.py` - Neural networks for price prediction
- `feature_engineering.py` - Feature selection and engineering
- `model_training.py` - Training pipeline management

## Dependencies

- TensorFlow/Keras for deep learning
- Scikit-learn for traditional ML
- NumPy/Pandas for data processing
