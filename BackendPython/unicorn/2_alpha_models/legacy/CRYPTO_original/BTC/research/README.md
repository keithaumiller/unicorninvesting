# BTC Research Directory

## Purpose
This directory contains research files and analysis related to Bitcoin (BTC) alpha model development.

## Contents
- **Research Papers**: Academic and industry research on BTC price prediction models
- **Market Analysis**: Historical Bitcoin market behavior studies
- **Model Research**: Comparative analysis of different ML approaches for BTC prediction
- **Feature Studies**: Research on effective features for BTC price modeling
- **Strategy Research**: Documentation of trading strategy research and backtesting results

## Directory Structure
```
research/
├── papers/                 # Academic and industry research papers
├── market_analysis/        # Bitcoin market behavior studies
├── model_comparisons/      # Comparative model performance studies
├── strategy_analysis/      # Trading strategy research
└── notebooks/             # Jupyter notebooks with research analysis
```

## File Naming Convention
- Research papers: `YYYY-MM-DD_paper_title.pdf`
- Analysis files: `YYYY-MM-DD_analysis_topic.md`
- Notebooks: `research_topic_analysis.ipynb`

## Purpose in LEAN Architecture
This directory supports the **Alpha Models** layer (Layer 2) by providing:
- Research foundation for BTC prediction models
- Documentation of model selection rationale
- Performance comparison studies
- Market behavior insights for strategy development
