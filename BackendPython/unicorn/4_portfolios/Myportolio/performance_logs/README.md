# Performance Logs

## 🎯 Purpose
This directory contains **performance attribution logs** generated by the comprehensive **PerformanceLogger** framework. These logs provide detailed analysis of all trading signals, risk decisions, trade executions, and portfolio state changes for root cause performance analysis.

## 📊 **Performance Logging Framework Overview**

The PerformanceLogger system tracks five key decision types throughout the trading pipeline:

### **1. Alpha Model Predictions** 
```python

    model_name="ETH_momentum_ensemble",
    prediction_value=0.0234,  # 2.34% return prediction
    confidence=0.87,
    features_used=["ma_5", "ma_20", "rsi_14", "volume_ratio"],
    prediction_horizon="1d"
)
```

### **2. Trading Signals**

## 📈 **Using Performance Logs for Analysis**

### **Log Analysis Workflow**
```python
# Example: Analyzing trading signal performance
from performance_logger import PerformanceLogger
import pandas as pd

# Load and analyze performance logs
logger = PerformanceLogger("myportolio")
log_data = logger.load_logs("2024-12-01")

# Analyze signal quality
signal_analysis = logger.analyze_signal_performance(log_data)
print(f"Average signal confidence: {signal_analysis['avg_confidence']}")
print(f"Signal win rate: {signal_analysis['win_rate']}")

# Risk decision analysis
risk_analysis = logger.analyze_risk_decisions(log_data)
print(f"Risk rejection rate: {risk_analysis['rejection_rate']}")
print(f"Top risk factor: {risk_analysis['top_risk_factor']}")
```

### **Performance Attribution Analysis**

## 🔧 **Debugging Common Performance Issues**

### **1. Over-Trading Detection**
Look for excessive trading signal frequency in logs:
```bash
grep "TradingSignal" performance_logs/myportolio_performance_*.log | wc -l
# If >50 signals/day, review strategy parameters
```

### **2. Risk Management Analysis**  
Check risk rejection patterns:
```bash
grep "decision_result.*rejected" performance_logs/myportolio_performance_*.log
# High rejection rate may indicate overly aggressive strategies
```

### **3. Signal Quality Assessment**
Analyze signal confidence scores:
```bash
grep "confidence_score" performance_logs/myportolio_performance_*.log | 
awk '{print $NF}' | sort -n
# Low confidence scores indicate poor signal quality
```
