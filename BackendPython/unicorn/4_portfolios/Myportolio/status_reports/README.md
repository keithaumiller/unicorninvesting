# Myportolio Status Reports

This directory contains status reports generated by the Myportolio status checker script.

## Directory Structure

```
status_reports/
├── README.md                          # This file
├── status_report_YYYYMMDD_HHMMSS.json # Current/recent status reports  
└── archive/                           # Historical status reports
    ├── status_report_*.json           # Archived status reports
    ├── risk_report_*.json            # Archived risk reports
    └── frontend_integration_test_*.json # Archived integration tests
```

## Status Report Generation

Status reports are automatically generated by:
- `utilities/statuscheck.py` - Main status checker script
- Various integration and validation scripts

## Report Contents

Each status report contains:
- **Portfolio Configuration**: Asset allocations, risk parameters
- **Alpha Models Status**: ETH Prophet, XGBoost, Ensemble model readiness
- **Risk Management**: Risk algorithm availability and calculations  
- **Data Connectivity**: IBKR integration and data source status
- **Execution Readiness**: Order management and execution systems
- **Algorithm Integration**: End-to-end workflow validation
- **Live Trading Readiness**: Overall readiness score and critical issues

## File Organization

- **Current Reports**: Latest status reports stay in main `status_reports/` directory
- **Archive**: Historical reports are moved to `archive/` subdirectory
- **Naming Convention**: `status_report_YYYYMMDD_HHMMSS.json`
- **Retention**: Reports are retained for auditing and trend analysis

## Usage

### Generate New Status Report
```bash
cd /workspaces/unicorninvesting/BackendPython/unicorn/4_portfolios/Myportolio
python utilities/statuscheck.py
```

### View Latest Report
```bash
ls -la status_reports/status_report_*.json | tail -1
```

### Archive Old Reports
```bash
# Move reports older than 7 days to archive
find status_reports/ -name "status_report_*.json" -mtime +7 -exec mv {} status_reports/archive/ \;
```

## Integration

The Drupal frontend automatically reads the latest status report from this directory to display:
- Portfolio readiness status on the web dashboard
- Component status indicators
- System health information
- Trading readiness assessment

Reports are accessed by the `PortfolioApiService` class in the web frontend.
