# Transform Scripts - Gold Layer Processing

## Purpose
Scripts for aggregating and creating business-ready datasets from silver layer data for analytical and trading purposes.

## Typical Scripts
- **silver_to_gold.py** - Aggregate silver data for business use
- **trading_indicators.py** - Calculate technical indicators and signals
- **portfolio_metrics.py** - Generate portfolio performance metrics
- **risk_calculations.py** - Compute risk measures and exposures

## Processing Pattern
```
3_silver → transformscripts/ → gold business-ready analytics
```

Gold transform scripts focus on:
- Business logic implementation
- Aggregations and calculations
- Trading signal generation
- Performance and risk metrics
