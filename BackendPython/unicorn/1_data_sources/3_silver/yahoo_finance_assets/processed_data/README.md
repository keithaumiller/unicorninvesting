# Silver Layer Processed Data

This directory contains processed market data files that are automatically generated by the data processing pipelines.

## ⚠️ Important: Data Files Not Tracked in Git

**All data files in this directory are automatically excluded from git tracking** to prevent repository bloat. This includes:

- `*.csv` files (market data)
- `*.json` files (metadata, reports, quality reports)
- All subdirectory data files (crypto/, forex/, metadata/, quality_reports/)

## Directory Structure

```
processed_data/
├── crypto/                    # Cryptocurrency market data (BTC, ETH, etc.)
├── forex/                     # Foreign exchange data (EURUSD, USDJPY, etc.)
├── metadata/                  # Asset metadata files
├── quality_reports/           # Data quality assessment reports
├── cross_asset_correlation_report.json
├── market_regime_analysis_report.json
├── market_regimes_1h.csv
└── processing_results.json
```

## Data Generation

These files are generated by:
- Yahoo Finance data collectors
- Market data processors
- Quality assessment algorithms
- Cross-asset correlation analyzers
- Market regime detection systems

## File Naming Convention

- Market data: `{ASSET}_silver_{timeframe}_{timestamp}.csv`
- Latest files: `{ASSET}_silver_{timeframe}_latest.csv`
- Metadata: `{ASSET}_{timeframe}_metadata.json`
- Quality reports: `{ASSET}_{timeframe}_quality.json`

## Working with Data

To regenerate data:
```bash
# Run data collection and processing pipelines
python BackendPython/unicorn/1_data_sources/yahoo_finance_data_collector.py
```

The data processing system will automatically populate this directory with the latest market data and analysis results.
