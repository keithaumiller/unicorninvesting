# Database Models

This directory contains SQLAlchemy database models for the financial data.

## Models

- `portfolio.py` - Portfolio and holdings models
- `market_data.py` - Market data and price models
- `user.py` - User and authentication models
- `analytics.py` - Analytics and performance models

## Dependencies

- SQLAlchemy for ORM
- PyMySQL for MySQL connection
- Pydantic for data validation
