# Business Logic Services

This directory contains business logic and data processing services.

## Services

- `market_data_service.py` - Market data collection and processing
- `portfolio_service.py` - Portfolio management logic
- `analytics_service.py` - Performance analytics
- `data_processor.py` - ETL and data cleaning
- `feature_manager.py` - Feature engineering management

## Dependencies

- Pandas for data processing
- YFinance for market data
- Alpha Vantage for additional data sources
