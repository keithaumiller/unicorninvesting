# ETH 1-Minute Data

This directory contains 1-minute interval data for Ethereum analysis and testing.

## ⚠️ Important: Data Files Not Tracked in Git

**All data files (*.json, *.csv) in this directory are automatically excluded from git tracking** to prevent repository bloat.

## Purpose

- High-frequency Ethereum trading data
- Integration testing data
- Algorithm validation datasets

## Data Generation

Data files are created by:
- Integration tests
- ETH data collectors
- Algorithm testing frameworks

Files in this directory are temporary and can be safely regenerated by running the appropriate data collection or testing scripts.
